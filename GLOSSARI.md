### Backlog
- Anglès: Backlog
- Definició: És una llista ordenada de tot el que s’ha de fer (millores, tasques...).
- Exemple: Afegim al backlog les tasques de crear el menú principal i millorar el disseny de la web.

### Branca
- Anglès: Branch
- Definició: Una línia de desenvolupament independent que permet treballar en noves funcionalitats o fer proves sense modificar directament la branca principal.
- Exemple: Creem una branca anomenada nova-branca per desenvolupar una millora sense afectar la branca principal.

### Clone
- Anglès: Clone
- Definició: Crear una còpia d’un repositori remot al teu ordinador per poder treballar-hi localment.
- Exemple: Fem un `clone` d’un repositori de GitHub per descarregar el projecte al nostre ordinador.

### Commit
- Anglès: Commit
- Definició: Una instantània dels canvis del projecte que guardem a l’historial del repositori local.
- Exemple: Fem un commit per guardar els canvis que hem fet al fitxer index.html.

### Fork
- Anglès: Fork
- Definició: Crear una còpia d’un repositori d’un altre usuari al teu compte de GitHub per poder modificar-lo independentment.
- Exemple: Fem un fork d’un projecte de GitHub per afegir-hi millores sense modificar el repositori original.

### Git
- Anglès: Git
- Definició: Un sistema de control de versions que permet registrar els canvis dels fitxers d’un projecte i recuperar versions anteriors.
- Exemple: Utilitzem Git per guardar l’historial dels canvis que fem al codi.

### GitHub
- Anglès: GitHub
- Definició: Una plataforma en línia que permet allotjar repositoris Git i compartir projectes, col·laborar amb altres persones i gestionar-ne el desenvolupament.
- Exemple: Pugem el nostre repositori a GitHub perquè altres desenvolupadors puguin veure el projecte i col·laborar-hi.

### HEAD
- Anglès: HEAD
- Definició: El punter que indica el commit actual sobre el qual estem treballant; normalment apunta a la branca activa.
- Exemple: Si estem a la branca main, el HEAD normalment apunta a l’últim commit d’aquesta branca.

### Issue
- Anglès: Issue
- Definició: Una tasca, un problema o una millora registrada en un repositori de GitHub per organitzar i fer un seguiment del treball.
- Exemple: Creem una issue a GitHub per registrar un error en el formulari d’inici de sessió i assignar-ne la resolució a un membre de l’equip.

### Iteracions
- Anglès: Iterations
- Definició: Cicles de treball en què desenvolupem, provem i millorem un projecte de manera progresiva.
- Exemple: Dividim el desenvolupament de l’aplicació en diverses iteracions per afegir-hi funcionalitats a poc a poc.

### Local repository
- Anglès: Local repository
- Definició: El repositori guardat al teu ordinador on Git registra l’historial dels canvis del projecte.
- Exemple: Fem un commit per guardar els canvis de index.html a l’historial del repositori local.

### Merge
- Anglès: Merge
- Definició: El procés d’integrar els canvis d’una branca en una altra dins del repositori.
- Exemple: Fem un merge de la branca nova-branca a main per incorporar-hi els canvis.

### Sprint
- Anglès: Sprint
- Definició: Termini curt de 1 a 4 setmanes, per completar un objectiu concret.
- Exemple: Durant un sprint de dues setmanes, l’equip treballa per crear el menú principal i implementar el sistema d’inici de sessió.

### Staging area
- Anglès: Staging area
- Definició: L’espai on selecciones els canvis que vols incloure en el pròxim commit.
- Exemple: Afegim el fitxer index.html a la staging area per preparar-lo per al commit.

### Taulell Kanban
- Anglès: Kanban board
- Definició: Tauler visual que permet organitzar i controlar l’estat de les tasques d’un projecte.
- Exemple: Utilitzem un taulell Kanban a GitHub Projects per organitzar les tasques de la web en les columnes "Per fer", "En procés" i "Fet".

### Working directory
- Anglès: Working directory
- Definició: La carpeta del teu ordinador on es troben els fitxers del projecte i on fas les modificacions abans de preparar-les per al commit.
- Exemple: Modifiquem el fitxer index.html dins la carpeta del nostre projecte.
